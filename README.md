# Biblical-Prose-SMT-with-prose-style-transfer
This is a standalone SMT model based on MOSES to translate across English and Portuguese. JSON source provided from thiagobodruk/bible. Using 10-fold cross-validation and BLEU-2, it optimizes a Dice-Coefficient Translation Model with a Bigram Language Model. Finally, heuristic SMT is evaluated against NLLB-200 to analyze performance on unseen data.
